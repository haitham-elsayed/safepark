# SafePark (اسم مؤقت)

ملصق QR على العربية يخلّي أي حد يبعت رسالة لصاحبها من صفحة ويب — من غير تطبيق ولا حساب للمرسل، ورقم صاحب العربية لا يظهر أبداً.

## التقنية وليه

- **Cloudflare Workers** — الموقع والـ API. مجاني (١٠٠ ألف طلب/يوم في الخطة المجانية)، سريع عالمياً، وHTTPS جاهز.
- **Cloudflare D1 (SQLite)** — قاعدة البيانات. مجانية ضمن نفس الحساب.
- **Cloudflare R2** — تخزين الصور. مجاني حتى ١٠ جيجا.
- **Hono** — إطار خفيف للراوتينج على الـ Workers.
- بدون سيرفر تقليدي وبدون أي اشتراك مدفوع. التنبيهات: بوت تيليجرام (مجاني)، إيميل عبر Resend (خطة مجانية)، وWeb Push ذاتي بدون خدمة مدفوعة.

## الخصائص (النسخة التجريبية)

- صفحة مرسل واحدة بسيطة: نوع العربية للتأكيد، اللوحة مخفية جزئياً، أزرار أسباب جاهزة، رسالة، صورة اختيارية، إيميل اختياري للتنبيه بالرد (مخفي عن المالك).
- عربي/إنجليزي تلقائياً حسب لغة موبايل المرسل.
- تأكيد استلام النظام فقط — حالة القراءة لا تظهر للمرسل أبداً.
- لينك متابعة خاص للمرسل يتحدث تلقائياً لما يوصل رد.
- لوحة تحكم المالك: عربيات متعددة، محادثات، رد، ردود سريعة (منها رد مؤقت بوقت الوصول)، حظر مرسل، تعطيل ملصق ضايع، ساعات هدوء ووضع "مش متاح" (الطوارئ تعدّي دائماً).
- صوت تنبيه مميز في لوحة التحكم عند وصول رسالة جديدة.
- مكافحة إزعاج: ٣ رسائل/ساعة لكل مرسل، ١٠ رسائل/يوم لكل عربية، اختبار إنسان (سؤال حسابي) بعد أول رسالتين، ووضع طلب آخر ٣ أرقام من اللوحة يتفعّل عند إساءة الاستخدام.
- الصور تظهر مضببة لحد الضغط عليها، وبيانات EXIF (ومنها الموقع) تُمسح من صور JPEG قبل التخزين.
- حماية من الخداع: تحذير واضح من طلبات الفلوس + زر إبلاغ + عرض الدومين الثابت على الملصق.
- حذف تلقائي: المحادثات بعد ٣٠ يوم، والمحادثات المُبلغ عنها بعد ٩٠ يوم (مهمة مجدولة كل ساعة).
- ملصق جاهز للطباعة (QR + تعليمات + تحذير) بمقاسات مقترحة للعربية والموتوسيكل.

## التشغيل محلياً

```bash
npm install
cp .dev.vars.example .dev.vars   # املأ القيم
npx wrangler d1 execute safepark --local --file ./schema.sql
npm run dev                     # wrangler dev على http://localhost:8787
```

بعدها افتح `http://localhost:8787/setup?key=<SETUP_SECRET>` لإنشاء حساب المالك وأول عربية (مرة واحدة فقط).

## الاختبارات

```bash
bash test/run.sh
```

بتمسح قاعدة البيانات المحلية، وتشغّل السيرفر، وتنفّذ ٥٦ اختبار طرف-لطرف (تسجيل، دخول، إرسال، ردود، حدود الرسائل، اختبار الإنسان، فحص اللوحة، حظر، إبلاغ، ساعات الهدوء، الصور وإزالة EXIF، ويبهوك تيليجرام، الحذف المجدول، PWA).

## النشر على Cloudflare (مجاني)

```bash
npx wrangler login                          # حساب Cloudflare مجاني، بدون بطاقة
npx wrangler d1 create safepark             # انسخ database_id في wrangler.toml
npx wrangler r2 bucket create safepark-photos
npx wrangler d1 execute safepark --remote --file ./schema.sql
# للأسرار: npx wrangler secret put SETUP_SECRET (وغيرها — انظر .dev.vars.example)
# عدّل APP_ORIGIN في wrangler.toml إلى رابط workers.dev النهائي
npx wrangler deploy
```

بعد النشر: افتح `/setup?key=<SETUP_SECRET>` مرة واحدة لإنشاء حسابك، واضبط ويبهوك البوت على `https://<الرابط>/api/tg/webhook` (ويستحسن مع `secret_token` مطابق لقيمة `TELEGRAM_WEBHOOK_SECRET`)، ثم اربط تيليجرام بإرسال أمر الربط الظاهر في لوحة التحكم (`/start <الكود>`) — الـ `/start` العادي لا يربط أي حساب.

ترقية قاعدة بيانات موجودة: نفّذ مرة واحدة `npx wrangler d1 execute safepark --remote --command "ALTER TABLE owners ADD COLUMN telegram_bind_token TEXT"`.

## بنية المشروع

```
src/index.js    الراوتس + المهمة المجدولة (نقطة الدخول)
src/sender.js   صفحات المرسل (صفحة الكود، المتابعة، النصوص ar/en)
src/owner.js    صفحات المالك (لوحة التحكم، المحادثة، الملصق)
src/html.js     التنسيق المشترك + الدخول/الإعداد
src/notify.js   تيليجرام + إيميل + Web Push + ويبهوك البوت
src/db.js       استعلامات D1 (حدود الرسائل وغيرها)
src/util.js     أدوات (تشفير كلمات السر PBKDF2، إخفاء اللوحة، ساعات الهدوء)
schema.sql      قاعدة البيانات
test/e2e.mjs    اختبارات طرف-لطرف (٥٦ اختبار)
scripts/gen-vapid.mjs   توليد مفاتيح Web Push
```

## قرارات مقصودة في النسخة التجريبية

- التسجيل مغلق: حساب مالك واحد يُنشأ من صفحة الإعداد، والتسجيل المفتوح للناس مؤجل.
- الدخول بإيميل وكلمة سر. التحقق برمز موبايل (SMS) مؤجل لأنه خدمة مدفوعة.
- إشعار المرسل بالرد يكون بالإيميل الاختياري أو لينك المتابعة — لا يوجد إرسال SMS.

## الخصوصية

رقم المالك لا يُحفظ ولا يظهر في أي صفحة مرسل. اللوحة تُعرض مخفية. إيميل المرسل لا يظهر في لوحة المالك. الصور تُجرد من بياناتها الوصفية قبل التخزين. لا يوجد تتبع ولا إعلانات.
